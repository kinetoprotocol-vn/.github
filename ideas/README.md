## Cấu trúc tư duy chung

Tất cả tài liệu đều sử dụng cấu trúc phân tích khép kín:

```
Đầu vào → Điều kiện → Đầu ra/Giá trị → Người hưởng lợi → Luồng phản hồi ngược
```

Đây là nguyên lý thiết kế xuyên suốt — từ Token economics đến CI/CD pipeline, từ ZK-circuit đến governance DAO.
